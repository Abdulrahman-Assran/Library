# 📚 Java CLI Library Management System

A console-based Library Management System built with **Java**, focusing on core **Object-Oriented Programming (OOP)** principles and robust terminal interaction.

## 🚀 Features
- **Member & Book Management:** Register new members and add books with unique serial numbers.
- **Borrowing & Returning System:** Securely track book availability and manage member book limits.
- **Interactive CLI:** Menu-driven interface with clean input handling.

## 🛠️ Concepts Applied
- **OOP Principles:** Encapsulation, Constructors, and separation of concerns (`Library`, `Book`, `Member`, and `Main`).
- **Data Structures:** Fixed-size array manipulation and linear search algorithms.
- **State Validation:** Atomic checks to prevent status corruption during borrowing/returning.
